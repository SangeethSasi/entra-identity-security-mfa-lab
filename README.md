# entra-identity-security-mfa-lab
Project Overview
This project demonstrates foundational Identity and Access Management (IAM) skills using Microsoft Entra ID Free. It focuses on cloud user provisioning, security group management, and Multi-Factor Authentication (MFA).
Objectives
- Create and manage cloud user accounts.
- Organize users into department-based security groups.
- Register Microsoft Authenticator for MFA.
- Test and document an MFA-protected sign-in.
Lab Environment
- Microsoft Entra ID Free
- Microsoft Entra admin center
- Microsoft Authenticator

Skills Demonstrated
- Microsoft Entra ID fundamentals
- Cloud identity provisioning
- Security group management
- Authentication methods
- Multi-Factor Authentication (MFA)
- Basic identity security testing
- Technical documentation
Limitations
- Lab uses Microsoft Entra ID Free.
- Dynamic membership rules were not implemented because they require a Premium license.
- Conditional Access policies were not configured.
- MFA enforcement for every test user was not independently verified.
- The MFA sign-in test was performed using my own account.
Conclusion
This lab provided hands-on experience with cloud identity administration, user and group management, and MFA registration and testing using Microsoft Entra ID.
